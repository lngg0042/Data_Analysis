# Data Analysis Projects (R)

Data analysis projects in R covering statistical inference, machine learning and natural language
processing. Each folder has its own README with results, method and figures.

| Project | What it does | Techniques |
|---|---|---|
| [**What Drives Trust in Institutions?**](1-wvs-institutional-confidence-analysis) | Compares South Korea with 57 other countries on confidence in institutions, using 100k World Values Survey responses | Data cleaning, Welch's t-test, stepwise regression, interaction models over time |
| [**Predicting Confidence with Machine Learning**](2-wvs-confidence-classification) | Predicts high/low confidence in government, unions and the women's movement from 30 survey attributes | Decision tree, Naive Bayes, Bagging, AdaBoost, Random Forest, neural network, ROC/AUC, feature importance |
| [**Text Mining & Network Analysis**](3-text-mining-document-networks) | Groups a 20-document, 4-genre corpus by vocabulary and sentiment | Document-term matrix, cosine clustering, sentiment analysis, igraph networks, Louvain communities |

**Tools:** R · tidyverse · ggplot2 · randomForest · adabag · nnet · tm · igraph

Raw data is not included. Each project's README says where to get it.
